# Advisor-OS

Tools for Medicine Hat Wealth Group.

- [`presentation-studio/`](presentation-studio/) — **MHWG Presentation Studio**: build polished,
  on-brand client presentations offline, by typing, with Copilot, or from JSON.
  Open `presentation-studio/dist/MHWG_Presentation_Studio.html` · [Quick start](presentation-studio/docs/QUICK_START.md)
- **MHWG Portfolio Builder** (same folder): clients, accounts and dollar values → a model portfolio
  per account → the household's combined allocation checked against the investor profile → a
  polished recommendation document.
  Open `presentation-studio/dist/MHWG_Portfolio_Builder.html` · [Quick start](presentation-studio/docs/PORTFOLIO_BUILDER.md)
